# PawJai Web Filter Reclassification

Last updated: 2026-09-02

## Issue

Some managed Wi-Fi networks block `pawjaipet.com` even though the production site is live and serves normal HTTPS responses.

Observed block page:

- URL: `pawjaipet.com/shelter`
- Category shown by network filter: `adult`
- User/private network IP shown in screenshot: `10.30.221.11`
- Browser context: LINE in-app browser on mobile

This block is generated by the network's filtering gateway, not by Vercel, Cloudflare, Supabase, or the PawJai app.

## Evidence

Production checks passed for:

- `https://www.pawjaipet.com/`
- `https://www.pawjaipet.com/dogs`
- `https://www.pawjaipet.com/shelter`
- `https://media.pawjaipet.com/file/pawjai/pawjaidogs/dog4A.jpg`

Current production responses include:

- HTTP 200 for public pages
- HTTPS with HSTS
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: SAMEORIGIN`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(), geolocation=(), browsing-topics=()`
- Canonical URLs on `https://www.pawjaipet.com`
- Sitemap at `https://www.pawjaipet.com/sitemap.xml`
- No stale `media.pawjai.co.th` URLs in the public feed or dog listing payloads

The `/shelter` page content is a partner shelter sign-in page for dog listing and adoption appointment management. It does not contain adult content.

## Likely Filter Vendor

The screenshot wording and layout closely match Palo Alto Networks / PAN-DB default URL filtering response pages:

```text
Web Page Blocked
Access to the web page you were trying to visit has been blocked in accordance with company policy.
Please contact your system administrator if you believe this is in error.
User:
URL:
Category:
```

Start with Palo Alto Networks Test A Site, then also submit to other common category databases if the blocking network cannot confirm its vendor.

## Requested Category

Ask for one of these, depending on the vendor's category list:

- Society
- Society / Lifestyle
- Pets
- Charitable Organizations
- Non-Profit / Advocacy
- Business and Economy

Do not request `adult`, `dating`, `gambling`, `phishing`, or generic high-risk categories.

## URLs To Submit

Submit the exact blocked URL plus the canonical host:

- `https://www.pawjaipet.com/`
- `https://www.pawjaipet.com/shelter`
- `https://www.pawjaipet.com/dogs`
- `https://pawjaipet.com/`

If a filter allows subdomain submission, include:

- `media.pawjaipet.com`

## Message Template

Subject: Request to reclassify pawjaipet.com from Adult to Pet Adoption / Shelter Platform

Hello,

Our website `https://www.pawjaipet.com` is being incorrectly blocked as `adult` on a managed Wi-Fi network. PawJai is a Thai dog adoption and shelter-matching platform. The `/shelter` page is a partner shelter login page used to manage dog listings and adoption appointments.

Please reclassify the following URLs away from `adult`:

- `https://www.pawjaipet.com/`
- `https://www.pawjaipet.com/shelter`
- `https://www.pawjaipet.com/dogs`
- `https://pawjaipet.com/`
- `pawjaipet.com`

Suggested category: Pets, Charitable Organizations, Society, Non-Profit, or Business and Economy, depending on your taxonomy.

The site serves normal HTTPS responses, canonical metadata, structured data, and a public sitemap at `https://www.pawjaipet.com/sitemap.xml`. It does not contain adult content.

Thank you.

## Follow-Up Checklist

1. Ask the blocked-network admin which filter vendor they use.
2. Ask whether the block is category-based or threat/reputation-based.
3. Ask them to allowlist `pawjaipet.com`, `www.pawjaipet.com`, and `media.pawjaipet.com` while vendor recategorization is pending.
4. Submit reclassification to the vendor.
5. Retest the same network after 24-72 hours.
6. Keep Search Console verified and sitemap submitted so reputation signals keep improving.
